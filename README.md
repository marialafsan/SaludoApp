# SaludoApp

Android greeting app built with **Kotlin** in **Android Studio** with the use of **XML** 

The user types their name and taps a button and a pop-up will show a personalized greeting, through a clean single-screen interface.

## Why

>Kotlin project developed in Android Studio to practice:
>
> - First steps with **Kotlin** and **Android Studio**
> - Designing a screen with **XML layouts** and **ConstraintLayout**, using a **vertical chain** to centre the components
> - Use of UI components: **TextView**, **EditText** and **Button**
> - Handling user interaction with a **click listener** and showing feedback with the use of ***Toast***
> - Managing texts and colors through **resources** (`strings.xml`, `colors.xml`) and customizing the look using the **Nunito** font
> - **Version control** using Git and GitHub
